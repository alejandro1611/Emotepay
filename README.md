# 🎭 EmotePay

> Instant, crypto-frictionless social payments for creators and streamers embedded right into live interactions.

Built for **Monad Metropolis Hackathon** (*Track: Consumer Products & Payments*).

---

## 🌟 What is EmotePay?

EmotePay transforms stream tipping into seamless, interactive social gestures. Instead of filling out credit card forms or navigating complex Web3 wallet confirmations, viewers can tip creators by sending animated emotes, stickers, and reactions in real time with near-zero latency.

### Key Features
- **Frictionless Onboarding:** Embedded wallets powered by Privy allow non-crypto users to join with single-click social logins.
- **Social Gestures as Tipping:** Replaces dry monetary transfers with expressive emotes (🔥, 🚀, 👑, 💎).
- **Real-Time OBS Stream Overlay:** Dynamic, animated alerts for creators that react instantly to viewer support.
- **Built on Monad Testnet:** Sub-second settlement with minimal transaction costs.

---

## 🛠 Tech Stack

- **Frontend:** Next.js 14 (App Router), TypeScript, Tailwind CSS
- **UI & Animations:** Framer Motion, Lucide Icons
- **Web3 Engine & Auth:** Privy (`@privy-io/react-auth`), Viem, Wagmi
- **Network:** Monad Testnet (Chain ID: `10143`)
- **Development Tooling:** Optimized for Apple Silicon (M2)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm / pnpm / yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/alejandro1611/Emotepay.git
   cd Emotepay
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to `http://localhost:3000` to see the app in action.
